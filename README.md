# 🔢 JavaScript Two Number Comparison

A simple JavaScript project that compares two numbers and determines which number is greater. It also checks whether both numbers are equal.

## 🌐 Live Demo
[Click Here to View Project](https://zaidy7433.github.io/java-script-two-number-comparisions-/)

## ✨ Features
- Takes two numbers as user input.
- Compares both numbers.
- Finds the greater number.
- Checks if both numbers are equal.
- Displays results using JavaScript alerts.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📚 What I Learned
- JavaScript variables.
- `prompt()` function.
- `alert()` function.
- `if`, `else if`, and `else` statements.
- Comparison operators (`>`, `<`, `==`).
- Number conversion using `Number()`.

## 🧮 Example

**Input:**
```text
First Number: 50
Second Number: 30
```

**Output:**
```text
50 is greater
```
